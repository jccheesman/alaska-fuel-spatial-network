### `class BridgeSpec`

A proximity connection policy (mmnet.connect_extras). `from_mode == to_mode` is a within-mode WELD (road↔road, ice↔ice); distinct modes are a cross-mode BRIDGE (ice↔road). A connector is added only when the real gap ≤ `max_dist` (meters).

**Fields:** `from_mode`, `to_mode`, `max_dist`


### `class ConnectToGiantSpec`

The connect-to-giant (shore-landing) pass: join every still-disconnected piece to the giant where it is within `max_dist` (meters). 0 disables it.

**Fields:** `max_dist`


### `class JoinComponentsSpec`

Stage 04: join every non-giant component to the giant when its nearest node is within `max_dist` (meters) of a giant node — a synthetic connector per component, iterated until stable. Acts on the ALL-mode component structure. 0 disables (no Stage-04 output).

**Fields:** `max_dist`


### `class SnapSpec`

Snap a mode's endpoints onto another mode's nodes at an anchor — a SHARED node, no transfer edge. Used for airports: each `from_mode` (Plane) leg endpoint that is an `anchor` (airport) point is moved onto the nearest `to_mode` (Road) node within `max_dist` (meters), so air connects to road AT a node.

**Fields:** `from_mode`, `to_mode`, `anchor`, `max_dist`
